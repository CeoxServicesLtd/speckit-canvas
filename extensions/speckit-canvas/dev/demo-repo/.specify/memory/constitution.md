# Demo Photos Constitution

Sample constitution used by the Spec-kit board's local demo repo.

## Core Principles

### I. User data stays private by default

Nothing is shared until its owner explicitly shares it, and every share can be revoked.

### II. Independently testable slices

Every user story must be deliverable and verifiable on its own.

### III. Measured, not guessed

Success criteria are measurable and technology-agnostic.
